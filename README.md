# python-task-manager
A Python-based CLI Task Management System built using OOP and JSON file storage. It allows users to add, complete, remove, and view tasks with persistent data saving. Designed as a beginner-friendly project to practice real-world programming logic and file handling concepts.

# Task Management System

A Python-based CLI Task Management System built using OOP and JSON file storage.

## Features
- Add Tasks
- Complete Tasks
- Remove Tasks
- View Tasks
- Persistent data storage using JSON

## Concepts Used
- Object-Oriented Programming (OOP)
- File Handling
- JSON
- CLI (Command Line Interface)

python main.py
